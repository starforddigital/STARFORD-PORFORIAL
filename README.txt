# STARFORD DIGITAL Portfolio Website

A responsive dark-themed graphic design portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colours, responsive styles and animations
- `script.js` — mobile navigation, reveal animations, portfolio filters and project modal

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For a local development server, you can use the VS Code Live Server extension.

## Important customisation before publishing
1. In `index.html`, find `255XXXXXXXXX` and replace it with your WhatsApp number, including Tanzania's country code `255` and without `+`, spaces or dashes.
2. Replace `hello@starforddigital.com` with your real email address.
3. The portfolio currently contains six original CSS sample artworks. Replace them with your real design work before presenting them as your portfolio. Edit the artwork blocks in `index.html` or add image tags for your project images.
4. Update the page title, description and any text to match your preferred bio and contact details.

## Publish
Upload `index.html`, `style.css` and `script.js` together to your web hosting or static hosting provider. Keep the three files in the same folder.
